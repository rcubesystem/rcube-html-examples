rcube-html examples

Every example from rcube-html.com as a plain HTML page — no build, no server. Start with My page, then change any examples/<name>.html.

Getting started

  • Introduction — What rcube-html is, how to install it, the starters for React, Angular, Vue, HTML and JSP, and your first schema-driven form.
  • Schema basics — Rows, columns, ids, props and children: how a schema describes a page.
  • Events & actions — Name an action in the schema (onChange, onClick, ...) and write it in your page.
  • Styles & themes — The stylesheet, your colours as CSS variables, a CMS theme, dark mode, and the grid's span and gap.
  • Angular, Vue, JSP & plain HTML — The same schema outside React: the <rcube-form> element in Angular, Vue, JSP and server pages, and plain JavaScript.

Text & layout

  • Text & HTML tags — Headings, paragraphs, links, images, lists, badges, progress bars and more.
  • Change elements at runtime — Change text, colors and classes, or hide, show and remove any element by its id.

Form fields

  • Input fields — Text, email, password, number, date, phone with a mask, color and checkbox inputs.
  • Selects & dependent selects — Drop-down lists, and a second list whose options follow the first one.
  • Radios, checkboxes, slider, textarea — Pick one, pick many, slide to a number or type a longer text.
  • Validation & submit — Required fields, patterns, ranges, dates and custom messages; submit only when valid.
  • Conditional fields — Show a field only when another field has a certain value.
  • Read & set values — Fill the form from code, read what the user typed, reset or clear it.
  • Rich text editor — A formatting toolbar you choose, your own tools, an HTML Source view; the value is cleaned HTML.
  • Repeatable entries — Let the user add the same group of fields several times (e.g. several contacts).

Containers

  • Cards, alerts, tooltips, popovers — Boxes and messages that hold other elements, including form fields.
  • Tabs & accordion — Split a long form into tabs or collapsible panels; errors open the right tab.
  • Modal & carousel — Pop-up dialogs with fields, and sliding image / content carousels.

Data components

  • Data table — Sorting, search, paging, selection, formats, totals, CSV export and colors.
  • Server paging — Thousands of rows: the server pages, sorts and searches; the table asks for one page at a time.
  • Remembered views & the chosen row — Tables keep each person's page, sort, search and filters for a week, with Reset; a radio per row and a highlighted chosen row.
  • Editable table & row actions — Edit cells, validate them, add / remove rows and add your own buttons to each row.
  • Charts — Bar, line, area, pie and donut charts whose data changes from fields and buttons.
  • Calendar — Day, week, month, year and schedule views; load events from an API on every view change.
  • File upload (drag & drop) — Drop, browse or paste files; validate them and upload with progress, cancel and retry.
  • Tree — A folder tree with checkboxes, drag & drop, rename, context menu and buttons that change it.
  • File explorer (lazy loading) — An S3-style explorer: folders load from an API page by page as you scroll, with server search.

Advanced

  • Languages — Write @keys instead of text and switch the whole form between languages.
  • Custom components — Add your own React component and use it in schemas by name.
